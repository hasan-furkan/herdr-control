# English UI glossary

Every visible string in the mods is English. Use these terms consistently; Herdr's own words win (space, tab, terminal, agent, machine). Short, plain, sentence case for messages; Title Case only for screen and section titles that were Title Case before.

## Time

- now
- `<1 min ago` / `${n} min ago`
- `${n} h ago`
- `${n} d ago` / yesterday
- `offline for ${n} d`
- Today / 14 Days / 30 Days
- h, min, s
- Jan Feb Mar Apr May Jun Jul Aug Sep Oct Nov Dec

Use `en-US` for locale formatting, or `en-GB` where the UI uses day-month order. Use a decimal point, as in `5.9 h`, and place the percent sign after the number, as in `85% traffic`.

- Waiting for usage data

- command failed / could not run

- `Could not open terminal: ${r}`
- `Could not send approval: ${r}`

- Spaces you open in Herdr appear here.

Keep new labels brief and preserve existing symbols and spacing when translating a label.
